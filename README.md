# Apollonia

A web application for a teeth whitening and dental cleaning service.  
The website provides business information, customer reviews, service descriptions, and an integrated shop where users can browse products, manage their cart, and complete checkout processes.

🌐 **Live Demo:**  
https://apollonia-whitening.netlify.app/

---

# Features

### Business Website

- Overview of the dental whitening service
- Information about available treatments
- Business location and contact details
- Customer reviews section

### Product Shop

- Browse products
- View product details
- Add products to cart

### Checkout Flow

- Enter delivery information
- Review order details before purchase
- Complete checkout process
